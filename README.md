## 🛠️ Tech Stack

### Frontend Framework
- **React** (v18.3.1) - UI library
- **TypeScript** (v5.5.3) - Type-safe JavaScript
- **Vite** (v5.4.1) - Lightning-fast build tool

### Styling & Components
- **Tailwind CSS** (v3.4.11) - Utility-first CSS framework
- **shadcn-ui** - High-quality React components
- **Radix UI** - Accessible primitive components (30+ packages)
- **Lucide React** - Beautiful icon library

### Forms & Data Management
- **React Hook Form** (v7.53.0) - Efficient form handling
- **Zod** (v3.23.8) - TypeScript-first schema validation
- **TanStack Query** (v5.56.2) - Server state management
- **Embla Carousel** (v8.3.0) - Touch-friendly carousel

### Additional Libraries
- **React Router DOM** (v6.26.2) - Client-side routing
- **Next Themes** (v0.3.0) - Dark mode support
- **Date-fns** (v3.6.0) - Date utilities
- **Sonner** (v1.5.0) - Toast notifications
- **React Resizable Panels** (v2.1.3) - Resizable layouts

### Development Tools
- **ESLint** - Code quality linting
- **PostCSS** - CSS transformation
- **Lovable Tagger** - Lovable-specific development utilities

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v16+) & **npm**
- Git (for cloning the repository)

### Installation

```bash
# Step 1: Clone the repository
git clone https://github.com/Shyam-Siddanthapu/siva-rupini-interiors-demo.git

# Step 2: Navigate to project directory
cd siva-rupini-interiors-demo

# Step 3: Install dependencies
npm install

# Step 4: Start development server
npm run dev
```

The application will be available at `http://localhost:5173` with hot module reloading enabled.

## 🌐 Deployment

### Deploy with Lovable
1. Open the [Lovable Project](https://lovable.dev/projects/cddd1987-826b-4a31-be4e-e35ea34c8b87)

3. Your app is live immediately

1. In Lovable: **Project → Settings → Domains**
2. Click **Connect Domain**
3. Follow the domain setup instructions

[Learn more about custom domains](https://docs.lovable.dev/tips-tricks/custom-domain#step-by-step-guide)

Build for production and deploy to your hosting service:
